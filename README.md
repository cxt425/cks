本项目为C语言课程设计作业，采用C语言开发控制台校园电动车管理系统。使用结构体存储车辆信息，支持信息增删改查，通过文件读写实现数据持久化保存，关闭程序后数据不会丢失。提供菜单式交互界面，方便使用者操作电动车档案。
运行环境和配置：
3.1 硬件接口
处理器：Intel Pentium 166 MX 或以上。
硬盘：空间500MB以上。
屏幕适配器：VGA接口。
系统运行内存：要求32MB以上。
3.2 软件接口
开发软件工具：VSCode + MinGW
文字编辑工具：VSCode
图形开发库：EasyX Graphics Library
数据库：本地TXT文本文件存储
操作系统：Windows 10 / Windows 11
3.3 控制
鼠标控制：USB鼠标点击界面按钮、输入框，完成页面切换、功能选择
键盘控制：USB键盘录入账号信息
程序控制：批量绘图接口控制画面刷新，文件接口控制车辆数据读写
