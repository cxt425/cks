# cks — 校园电动车管理系统

> 华中科技大学课程设计项目：基于 EasyX 图形库的 Windows 桌面程序，管理**个人电动车**与**共享电动车**两类业务。

## 项目简介

程序以 480×640 单窗口、多页面状态机的方式运行：所有界面由 EasyX（GDI 封装）自绘，鼠标点击与键盘输入由程序自行完成命中检测与输入框管理。车辆数据以 `|` 分隔的文本文件保存在程序目录，关闭后不丢失。

> 旧版 README 中“C 语言、控制台程序”的描述与代码不符，本版已按实际实现更正为 **C++ + EasyX 图形界面**。

## 功能

### 个人电动车

| 功能 | 说明 |
| --- | --- |
| 注册上牌 | 车牌唯一性校验 + 字段格式校验，通过后追加写入 `personal_vehicle_data.txt` |
| 年审管理 | 按车牌查询车辆，展示当前状态，更新下次年审日期与年审状态 |
| 信息变更 | 按车牌查询后修改车主姓名、院系、联系方式、车型、备注 |
| 报废管理 | 选择报废原因（车体损坏 / 达到使用年限 / 丢失无法找回 / 其他），确认后标记报废并禁止后续操作 |
| 出入校园 | 添加入校/出校记录（车牌 + 类型 + 日期），按车牌查询并以滚动列表浏览历史记录 |

### 共享电动车

| 功能 | 说明 |
| --- | --- |
| 账号登录 | 用户名 + 手机号 + 验证码登录，退出后回到首页 |
| 输入用车 | 输入车辆编号开锁，展示车辆状态、可用电量与起步价 |
| 还车结算 | 展示用车时长、骑行里程、应付金额，确认还车并支付 |
| 故障报修 | 选择问题类型（无法锁车 / 刹车异常 / 电量异常 / 车身损坏），补充文字描述后提交 |
| 我的订单 | 按手机号筛选历史订单，支持滚动条拖动与滚轮翻页 |

## 交互方式

- **鼠标**：左键点击自绘按钮/卡片；订单列表、出入记录列表支持拖动右侧滚动条。
- **键盘**：`Tab` 切换输入框，`Backspace` 删除（中文按双字节回退），`Enter` 提交当前表单。
- **中文输入**：通过 `WM_CHAR` 逐字节追加，绘制时统一转 ANSI 后用 `outtextxy` 输出。

## 技术栈

| 项目 | 说明 |
| --- | --- |
| 语言 | C++（`-std=c++17` 即可） |
| 图形库 | EasyX Graphics Library（Windows GDI 封装） |
| 构建 | VSCode + MinGW-w64，g++ 直接编译 |
| 界面 | 480 × 640 固定窗口，自绘控件，`BeginBatchDraw` 批量刷新防闪烁 |
| 数据 | 本地 TXT，`\|` 分隔，无数据库、无网络 |
| 编码 | 源文件与界面按 ANSI(GBK) 处理，数据文件读写时转换为 UTF-8 |

## 目录结构

```text
cks/
├─ main.cpp                     # 入口：初始化窗口、消息循环、页面状态机
├─ DrawPage.cpp / DrawPage.h    # 全部页面绘制（首页、个人车、共享车）
├─ MouseCtrl.h                  # 全局鼠标命中检测 GlobalMouseCheck
├─ personalregistration.h/.cpp  # 个人车注册、校验、落盘、输入处理
├─ personalinspection.h         # 个人车年审
├─ personalscrap.h              # 个人车报废
├─ personalaccess.h             # 个人车出入校记录
├─ sharedsignout.h              # 共享车登录 / 退出登录
├─ sharedusevehicle.h           # 共享车用车
├─ sharedrepair.h               # 共享车报修
└─ xiaohui.png                  # 首页校徽图片（须与 exe 同目录）
```

> 各模块的实现放在同名 `.cpp` 中（例如 `personalregistration.cpp`），头文件只放结构体定义与函数声明。

## 数据存储

程序运行目录下维护三份文本文件，每行一条记录，字段以 `|` 分隔，文件内容为 UTF-8：

**personal_vehicle_data.txt** —— 个人车档案

```text
车牌号|车主|院系|学号|手机号|车型|注册日期|状态
A1234|张三|机械学院|U202312345|13800138000|雅迪|2026-09-01|正常
```

**shared_vehicle_data.txt** —— 共享车数据，至少包含 `用户名|手机号` 两列，用于登录与订单归属校验。

**shared_use_records.txt** —— 共享车订单流水

```text
手机号|车辆编号|骑行时长|骑行里程|金额|状态
13900139000|B2048|35|6.2|3.5|已支付
```

> 数据文件在首次写入时由程序自动创建（`fopen` 追加模式）；删除后不可恢复，建议定期备份。

## 输入校验规则

| 字段 | 规则 |
| --- | --- |
| 车牌号 | 5 位：1 位大写字母 + 4 位大写字母或数字 |
| 学号 / 工号 | 10 位：1 位大写字母 + 9 位数字 |
| 手机号 | 11 位数字，且以 `1` 开头 |
| 注册日期 / 年审日期 | `YYYY-MM-DD` |
| 车主姓名 / 院系 | 至少 2 个字符 |
| 中文输入 | 除受控字段外，允许中文、字母、数字、空格与常用符号 |

## 构建与运行

1. Windows 10/11，安装 **MinGW-w64**（位数需与 EasyX 库一致）。
2. 安装 EasyX 的 MinGW 版本（提供 `graphics.h` 与 `libeasyx`）。
3. 在仓库根目录编译（库文件名以你的安装为准，按需调整 `-l` 参数）：

```bash
g++ -std=c++17 main.cpp DrawPage.cpp personalregistration.cpp \
    personalinspection.cpp personalscrap.cpp personalaccess.cpp \
    sharedsignout.cpp sharedusevehicle.cpp sharedrepair.cpp \
    -o cks.exe -I"<easyx>/include" -L"<easyx>/lib" \
    -leasyx -lgdi32 -lole32 -lwinmm
```

4. 将 `xiaohui.png` 放到 `cks.exe` 同目录后双击运行（建议在 VSCode 的 `tasks.json` 中把上述命令配置为构建任务，并使用 GBK 代码页编译中文源码）。

## 资源与字体依赖

- `xiaohui.png`：缺失时首页与登录页的图片区域为空白。
- 字体：`黑体`、`宋体`、`华文行楷`；缺少 `华文行楷` 时校名会回退到默认字体。
- 运行环境需支持 GDI；程序不访问网络。

## 已知限制

- 数据为单机 TXT 文件，无并发保护、无权限控制，**不适合真实运营场景**。
- 车牌、学号等格式规则为课程设定，与真实车牌/学号规则不同。
- 界面尺寸固定 480×640，未做 DPI 缩放适配。
- 共享车登录、结算与报修均为本地演示逻辑，无服务端校验。
